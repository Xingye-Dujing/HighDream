# HighDream ([English version description](./README-EN.md))

## 项目概述

### 这个项目是什么？

HighDream 是一个基于 **Python** 和 **SymPy** 的符号计算工具。它采用模块化设计，通过**广度优先搜索(BFS)和规则驱动**，实现对微分、积分、极限、矩阵和等价改写等数学问题的自动化求解，并**提供求解过程**。

### 为什么创建这个项目？

我在上高中时苦于立体几何和圆锥曲线的计算，就一直在想如果计算机能够帮助我自动计算并提供计算过程就好了。高中没有时间去搞这个，大一又忘了这件事。于是拖到今年 9 月，大二开学后终于开始了它的制作。前前后后将近 3 个月，断断续续地终于完成了它的大概框架。

### 为什么命名为 HighDream？

如上所述，这个想法源于高中时期 `(The Dream of High School)`。我查了一下，`high dream` 意味着令人陶醉的梦想。虽然网易有道词典提示这可能意味着无法接受现实，但我只取其陶醉之意。**我希望未来计算机能拥有强大的智能，促进人类理论知识的发展。** 因此，命名为 `HighDream` 既代表了我的高中想法，也代表了我对未来的幻想。

## 特性

- 逐步求解：显示完整的计算过程，便于教学和理解
- 规则模式匹配：基于模式匹配的规则应用，没有 AI 参与，输出结果稳定性高
- 多领域支持：微分、积分、极限、矩阵运算、等价改写
- 定积分：在积分单元格填写上限（下限可选，默认 0）即可计算定积分，展示"先求原函数、再用牛顿-莱布尼茨公式代入上下限"的过程；不定积分仍自动附加积分常数 C
- 反常积分输入：定积分的上下限支持 oo、∞、infinity、负无穷/正无穷/无穷大 等任意记法，解析前统一归一化为 SymPy 的 ∞，使端点为无穷的积分（如 ∫₁^∞ 1/x²=1、∫₀^∞ e⁻ˣ=1）都能正常给出完整分步与结果；同时修正反常极限那一行泄漏字面 None、以及被积函数 1/x² 显示多余前导 1（parse_latex 遗留的单位系数）两处渲染问题
- 换元回代修复（重要）：三角代换引入的临时变量带 real/positive 假设，此前写回时把父积分按无假设符号重建，导致代入静默失效、正确结果被丢弃并输出畸形式 ∫…(u,asin x)。现改为复用引擎已存的真实操作（保留假设身份）并从积分自身的 limits 取积分变量，使一大批换元型积分完整闭合：∫1/√(1−x²)=asin x、∫√(1−x²)、∫1/√(x²±1)=ln|x+√(x²±1)| 型、∫1/(x²√(x²−1))、∫x²/√(1−x²)、∫1/√(x²+2x+3) 等；网页与手动分步（/rule_select）两条路径同时修复，不再向用户泄漏未算完的积分；三角代换说明里的 dθ 也改为随实际变量渲染（du/dv）
- 定积分两类缺陷修复：① 区间内部瑕点扫描遇到周期分母（sin/cos/tan）时，solveset 在 Reals 上返回无穷解集导致定积分卡死（如 ∫₀^{π/2} sin/(sin+cos) 无结果）；现把候选瑕点限制在积分区间 Interval.open(a,b) 内求解并对无界情形设迭代上限，同时对含字母端点（无法比较 a≤b）安全跳过，卡死变为正常求解（∫₀^{π/2} sin/(sin+cos)=π/4、∫₀^{π/2} sin/(1+cos)=ln2）；② 有限端点的反常积分（如 ∫₀¹ ln x）此前因直接代入得 NaN 而返回 nan，现识别“非有限值”并取单侧极限，正确给出 −1
- 根式代换分支修复：对二次根式（如 ∫√(x²+2x)）反解 x 有 ±两支，此前误取 x≤−2 支，导致在课本默认“变量为正”的 x>0 区间上原函数求导恰为被积函数的相反数（符号反了）。现按“assume 变量为正”约定选取 x 随 u→+∞ 增长为正的分支，使 √(x²+2x)、√(x²−2x)、√(x²+1) 等在 x>0 上给出正确符号的原函数
- 定积分计算技巧（区间再现/对称）：新增两类分步定积分简算，仅在有限数值上下限且无内部瑕点时启用（绝不掩盖发散），手动 /rule_select 路径不自动套用：① 镜像·国王公式 I=∫ₐᵇf(x)dx=∫ₐᵇf(a+b−x)dx，两式相加得 2I=∫ₐᵇ[f(x)+f(a+b−x)]dx；当和式为常数 c 时 I=c(b−a)/2，逐步给出（如 ∫₀^{π/2} sin/(sin+cos)=π/4、∫₀^{π/2} 1/(1+tan³x)=π/4，后者此前需 21 秒、现瞬间得出）；② 奇偶性：区间 [−A,A] 上奇函数直接得 0（如 ∫₋₁¹ x³cos x、∫₋₂² x/(1+x²)）
- 有理式分母扩展分解：对形如 ax⁴+bx²+c（c/a>0）的双二次分母，用闭式实因式分解 (x²+√(c/a))²−(2√(c/a)−b/a)x² 自动求出分裂域 √(c/a)、√(2√(c/a)−b/a) 并据此做部分分式，把在 ℚ 上不可约、但在 ℝ 上可分解为两个实二次因式（如 1/(x⁴−2x²+2)、1/(x⁴+1)、1/(x⁴+4)）的题纳入现有配方/反正切/对数积分流程逐步求解；此前这类分母因扩展不够而无法分裂、BFS 空转超时
- 偏导数：微分单元格可指定任意一个字母变量作为求导变量，其余符号自动视为常数，即可求偏导
- 积分规则扩展：正割/余割/余切的平方、幂递推，以及 tan·sec、cot·csc 乘积的直接积分，避免落入万能代换产生的冗长结果；sin^m·cos^n 的偶次幂积先经倍角降幂再逐项积分
- 符号矩阵化简：线性代数新增“符号矩阵化简”，对 A·A⁻¹=I、I·A=A、(A⁻¹)⁻¹=A、(AB)⁻¹=B⁻¹A⁻¹、(AB)ᵀ=BᵀAᵀ、A·(B+C)=A·B+A·C 等给出分步结果（大写符号视为 n×n 方阵）
- 高阶导数：diff(expr, x, n) / dⁿ/dxⁿ 逐阶求解——每一阶都完整走规则引擎并把上一阶结果代回，绝不 .diff(n) 黑箱跳步
- 矩阵新算子：迹 tr(A)、零空间 N(A)、列空间 C(A)、行空间 R(A)（先给行最简形与主元列，再给一组基与维数）、伪逆 A⁺ pinv（列满秩/行满秩/秩亏分情形）、Jordan 标准形 jordan（A=PJP⁻¹，给 J 与过渡矩阵 P）、二次型正定判定 definite（按特征值判定正定/负定/半正定/半负定/不定，推导中同时展示顺序主子式）、特征多项式 charpoly（p(λ)=det(A−λI) 展开与因式分解）；trace 可作为标量参与组合运算，矩阵值结果不落入标量算术时给友好提示
- 数值解初值问题(IVP)：欧拉法 euler、改进欧拉 heun、四阶龙格库塔 rk4，按步长 h 逐步推进并列出每一步的 x_k 与 y_k(如 euler(y'=x+y, y(0)=1, 到 x=1, 4 步))，给出 y(x_end) 的数值近似
- 数值求根：二分法 bisection(需异号端点)、割线法 secant、不动点迭代 fixedpoint，与已有牛顿法 newton 一起，逐步列出每次迭代值直至收敛(如 bisection(x^2-2, x, 1, 2, 8) → 1.414…)
- 复数 n 次方根：nthroots(w, n) 按棣莫弗公式给出 w 的全部 n 个根(先给模、辐角与通式 z_k=|w|^{1/n}·e^{i(θ+2πk)/n}, 再逐一列出 k=0..n-1 各根)
- 审计修复：商法则此前因条件写错而失效(除法现走商法则)；有限和 Σ_{k=1}^{n} 此前误入无穷级数敛散性判“发散”，现走闭式求和(Faulhaber/等比/裂项)，无上限才判敛散；收敛半径改用输入的求和变量并对振荡系数回退到柯西-阿达马根值判别，不再崩溃；simplify 单独调用不再返回空结果
- 审计修复(二)：留空下界默认 0 曾是 Python int、使区间内部瑕点扫描跳过，导致 ∫₀²1/(x−1)、∫₀²1/(x−1)² 等发散积分被错误地给出有限值；现统一先 sympify 再判非有限值并按瑕点拆分，正确判为发散。Schur 分解在重复特征值(如 [[1,0],[0,1]])与秩亏矩阵上曾崩溃(IndexError)，现改为精确的递归不变子空间构造（T 上三角，复特征值保留 2×2 块）。编辑器提供的 `\frac{d^{2}}{dx^{2}}`、`\frac{\partial^2}{\partial x^2}` 等高阶模板此前解析失败甚至静默给出“partial*y”式错解，现按逐阶求导正确识别。奇异的对角/三角特殊矩阵求逆不再返回含 zoo 的伪逆，改为明确提示不可逆；方法三·特征值法求秩现按特征值代数重数正确计数，不可对角化矩阵(如幂零 Jordan 块)明确拒绝而非给错值；根式幂被误判为可用万能代换、更换序数值边界崩溃、整数次幂判定过宽、高阶 LaTeX 盲区、符号定积分结果误标“发散”等亦已修正。order、解析深度、L'Hôpital 次数服务器端统一设限（此前可传入天文数字长时间占用 worker）；Markdown/SVG 渲染与蓝图节点字段此前可经导入的受信 `.json` 文档触发 XSS，现全部先转义并对链接 URL 限制协议；快照标题限长、整个应用请求体上限 4MB、`/api/sympy_execute` 不再回传服务器 traceback；手动分步会话与方法树快照进出口加锁并把失败规则的写回原子回滚。
- 高等数学扩展：切线/线性化/临界点(极值)/牛顿法、弧长/旋转体体积(圆盘·柱壳)/旋转曲面、累次/二重积分(矩形区域, 内外层均逐步积分)、隐函数与参数方程求导、极坐标面积与斜率、泰勒/麦克劳林展开(各阶导数经规则引擎逐级求解)、级数敛散性(第n项/比值/根值/莱布尼茨/p-级数 逐法定名判定)、反常积分(端点为无穷或瑕点时取单侧极限判敛; 区间内部含瑕点时按瑕点拆为多个反常积分逐段收敛判定, 发散者如实报发散而非误套牛顿-莱布尼茨)、含字母参数的极限(固定极限变量, 其余符号视为常数参数, 如 sin(a*x)/x→a、(1-cos(a*x))/x²→a²/2、(1+a/x)^x→e^a)、绝对值/取整/符号函数的单侧极限(接近侧符号确定时先去绝对值再求, 如 |x|/x 右→1、左→-1)、微分方程(一阶: 可分离变量/齐次方程 y'=f(y/x)/线性积分因子/伯努利方程/恰当方程势函数/非恰当方程的积分因子 µ(x) 或 µ(y); 二阶及以上: 常系数齐次特征方程(含重根与共轭复根)/非齐次常数变易法/欧拉变系数齐次; 高阶常系数齐次按特征多项式在有理域因式分解逐因子配对基; 缺 y 的二阶方程降阶 y''=f(x,y')(令 p=y' 化一阶再积分); 全程逐步求解, 仅其余情形回退 dsolve)、数值积分(梯形/辛普森)、中值定理/罗尔定理、幂级数收敛半径与收敛域(端点判定)+逐项求导/积分、复数化简(a+bi)/极坐标·指数形式/复数方程求根、柱壳法体积、复数高次幂(棣莫弗)
- 极限求解增强：等价无穷小代换(equivalent_infinitesimal)——对乘除结构中的独立因子按 u→0 代换(sin u~u、tan u~u、arcsin u~u、arctan u~u、1−cos u~u²/2、e^u−1~u、ln(1+u)~u), 每步标注"等价无穷小代换"; 关键安全约束: 绝不代入加减项内部(sin x−x 换 x 会得 0 的陷阱), 故这类差式自动改走洛必达(如 (sin x−x)/x³ 仍正确得 −1/6); 代换优先于普通乘除拆分但排在孤立重要极限(sin x/x、(e^x−1)/x 等"重要极限"直示)之后, 互不遮挡。另: 洛必达链新增成本受限化简 `_simp`(恒等的 cancel/together/expand_trig, 仅在表达式不增大时采用否则回落完整 simplify), 跳过被 BFS 反复触发的昂贵 trigsimp, notebook-limit 最慢格由 2.5s 降至约 1.7s, 结果与中间步骤逐格核验不变。新增 tests/test_limit_equiv_infinitesimal.py 与 docs/notebook-equivalent-infinitesimal.json
- 多元与向量微积分扩展：多元偏导/梯度(gradient)、Hessian 矩阵与二阶判别式 D=hessian、雅可比矩阵与行列式(jacobian)、方向导数(directional)、旋度(curl)与散度(divergence)、拉格朗日乘数条件极值(lagrange)；三重积分(长方体逐层)、积分换序(changeorder, 线性边界自动改先 x 后 y 并逐块求解, 换序前后精确核验相等)、柱/球坐标三重积分(自动带雅可比 r 与 ρ²sinφ)；曲线积分——第一类 ∫_C f ds(lineint, 曲线参数方程以 | 分隔, 弧微分 |r'(t)| 由规则引擎求导)与第二类功 ∫ P dx+Q dy(lineint2/work)；曲面积分——第一类 ∬_S f dS(surfint, 曲面取图 z=g(x,y), dS=√(1+g_x²+g_y²))与第二类通量 ∬_S F·dS(flux, 上侧定向 −P·g_x−Q·g_y+R)。所有偏导经 DiffCalculator、定/二重积分经 IntegralCalculator 逐步求解, 曲线/曲面积分再以复合 Simpson 数值核验, 不一致则诚实拒绝而非给出错值。示例: lineint(x^2+y^2, cos(t)|sin(t), t, 0, 2*pi)=2π、lineint2(y|-x, cos(t)|sin(t), t, 0, 2*pi)=−2π、surfint(1, x+y, x, y, 0, 1, 0, 1)=√3、flux(x|y|z, 1-x-y, x, y, 0, 1, 0, 1)=1
- 万能输入框：新增“自动识别(微积分+线性代数)”默认题型，一个框内写完整算式即可，程序按算子/结构分派到全部计算功能——结构式 d/dx、∫、∮、lim、Σ、矩阵字面量(A+B/A*B/单矩阵行最简)、\det 等裸式；函数式 det/rank/inverse/rref/eigenvals/svd/lu/diagonalize/orthogonalize/dependence/project/transpose、diff/int/limit/sum/taylor/tangent/linearization/critical/newton/meanvalue/arclength/volume/shell/surface/implicit/parametric/ode/numerical/complex/demoivre/msimplify/simplify、矩阵运算 add/subtract/multiply(A,B) 等；无算子的普通表达式则化简，无需先选类型（类似 Maple）
- 万能输入框·任意组合递归求值：算子可嵌入任意初等运算，程序由内而外递归消解——先把每个内层算子交给它自己的分步引擎求解并取回结果值，代回外层，再继续消解外层，最后把纯初等合并也给出分步，整条推导用嵌套子块呈现（外层一行一步，内层算子的完整步骤缩进归属其所在步骤），全程绝不做 sympy 黑箱跳步。例：3*diff(x,x)、sin(x)+int(x^2,x)、diff(int(x^2,x),x)、det([[1,2],[3,4]])+rank([[1,0],[0,1]])、volume(x,x,0,1)*3、taylor(e^x,x,0,2)+1；矩阵值结果(inverse/rref)不落入标量算术、切线方程/极值点/收敛判定等“教学对象”不参与算术时，均给出友好提示而非错误结果；单独一个顶层算子或符号矩阵式(如 msimplify(A·B·B⁻¹)) 仍走原快速通道，行为不变
- 所见即所得输入：单元格输入区为交互式 LaTeX 渲染编辑器(本地内置 MathLive, 离线可用), 输入即渲染、不再分离预览框; 提供模板键盘与符号面板, 分数/根号/上下标/导数/定积分/积分/求和/极限/偏导/三角/常数/矩阵均可一键插入并留下可填写占位; 求导/积分/极限/级数等按题型预设模板与默认变量; 单矩阵线性代数题型(行列式/秩/逆/特征值/行最简/LU/对角化/SVD/正交化等)输入渲染为真实矩阵并预置可填的 2×2 矩阵骨架; 双输入题型(矩阵运算/解线性方程组 Ax=b/向量投影/线性变换)提供两个矩阵编辑器; 线性方程组文字录入与符号矩阵表达式保留文本输入
- 隐式单元格（Maple 文档模式）：单元格默认无边框、无“Calculator:”提示、不显示控件栏，页面呈现为连续的“输入→结果”文档；鼠标悬停或聚焦时才在输入上方浮出控件栏（运行/题型/各题型专有参数/变量/缓存/键盘），聚焦单元格以左侧细色条标示；在公式编辑器中按回车即求值并在下方自动生成新的隐式输入（类似 Maple），文本型输入框用 Ctrl/⌘+回车求值（保留换行）；加载笔记本后文档末尾始终保留一个可编辑的空输入

- 历史快照与快捷键：不再自动保存；顶部“操作”菜单新增“历史快照”，可随时把当前笔记本存入服务端 SQLite 数据库（cache/snapshots.db），并在快照列表中手动恢复到任意一次（恢复前会把当前内容另存一份安全快照）；Ctrl/⌘+S 直接保存为 JSON 文件
- 假设输入：每格控件栏新增“假设”文本框(随笔记本保存/加载), 填入如 `x>0, y real`(逗号/分号/且 分隔, 支持 >0 <0 >=0 <=0 !=0 ==0 及 real/positive/integer/... 词式), 求导与(不/定)积分会把“依假设化简最终结果: …”作为一条显式分步追加, 使 sqrt(x²)→x、log(x²)/2→log(x)、∫1/x→log(x) 等符合课本假设; 采用受限的符号往返(仅替换被约束的符号化简再换回), 未约束符号保持不动(不会误把 sqrt(y²) 也当成 y), 且不改动求解符号身份/换元流程; 带假设时自动绕过结果缓存(缓存键不含假设字段)以免串答案; 非法假设安全降级为“无假设”, 不报错
- 分步规则卡片：求导/积分/极限的结果下方新增默认折叠的“分步规则卡片”面板, 复用已有的 /api/steps 结构化步骤接口把整块推导逐步拆成独立卡片(每张卡片头部标注该步所用规则/说明、体内为该步数学式), 便于逐步聚焦阅读; 纯前端渲染, 上方原始 align 整块显示保持不变(不影响导出), 无需后端改动

## 架构设计

本项目主要由**四个**架构组成：

1. 用于微分、积分、极限和行列式计算的架构（`BaseCalculator` + `BaseStepGenerator` + `RuleRegistry`）
2. 用于矩阵相关操作的架构（`CommonMatrixCalculator` + `MatrixStepGenerator`）
3. 用于前端调用后端进行计算的架构（Flask 蓝图 + `task_manager` 异步任务）
4. 用于手动规则选择与全规则遍历方法树的架构（`BaseManualStepSolver` 及各领域子类、`MethodTreeEnumerator`）

计算入口进一步拆成可替换的小模块：`core/operator_registry.py` 只存操作表，`core/latex_syntax.py` 负责结构 LaTeX ↔ 算子调用的归一化，`core/input_validation.py` 负责所见即所得/文本/矩阵输入校验与用户错误映射，`utils/expression_utils.py` 提供括号匹配与顶层分割等通用工具；`routes/api.py` 仅聚合 `compute_api` / `matrix_api` / `sympy_api` / `manual_api` / `method_tree_api` / `snapshot_api` 六个路由模块。

## 使用注意事项

0. 在使用时，不要退出命令行（黑框窗口）
1. 乘法运算符 `*` 绝对不能省略！ `ab` 会被解析为一个单独的符号，而不是 `a*b`
2. 反三角函数是 `asin()`, `acos()`, `atan()`，不是 `arcsin()`, `arccos()`, `arctan()`
3. 不要用 `e**` 或 `e^` 而是要用 `exp()`. `e` 会被解析成一个类似于 `x` 的字母变量。`exp()` 才是定义好的自然指数函数。
4. 无写入权限的环境（如 Vercel）可用 `HIGHDREAM_CACHE_DIR` 环境变量重定向 SQLite 缓存目录。
5. 表达式输入已启用安全净化，仅允许数学语法，不会执行任意 Python 代码。
